三、立项依据
（一）行业研究现状和发展动态
近年来低空经济加速落地，城市末端物流、楼宇巡检、应急搜救等场景倒逼无人机
在密集城区实现全自主飞行。当前行业痛点集中在：城区楼宇错落形成不规则三维密闭
空域，静态建筑 + 随机通航异构飞行器构成动静态耦合障碍，传统单一路径算法无法
兼顾全局最优与动态突发避障，多数仿真依赖人工简易建模，和真实城区环境差距大。
算法研究层面：A及其衍生（D-Lite、Theta）多用于静态全局路径搜索，人工势场
法实时性优异但普遍存在局部极小、动态障碍响应滞后缺陷；Zhang 团队提出 CBMBA A
* 算法，采用多层分区 + 双向自适应步长搜索，优化静态建筑群全局寻优效率，在城
区低空场景路径成本、运算耗时较传统 A * 大幅优化，非常适配静态楼宇全局规划；
北航 HPER-D3QN 算法，依托分层优先级经验回放 + DTPA 动态威胁评估，可针对有人 /
无人异构飞行器、风场扰动等不确定动态威胁自适应避障，解决传统强化学习训练收敛
慢、高密度空域避障成功率低的短板，是动态障碍物规避最优参考方案。
仿真平台层面：国内北航、南航、哈工大等院所多采用分立仿真环境开展算法验证，
缺少 UE4+AirSim+PX4 一体化全链路仿真架构，现有研究大多割裂全局规划与动态避
障，且仿真场景多为简易人工障碍物，基于真实城市地图的动静态联合避障仿真体系稀
缺，难以支撑工程化落地验证。
（二）主要研究内容
1.基于 OSM 数据的 UE4 三维真实建筑群场景建模
依托 OpenStreetMap 开源城市地理、建筑轮廓数据，Blender 完成建筑三维轻量
化建模与纹理优化，模型批量导入 UE4 引擎搭建精细化城区仿真空域，配置不同高度
楼宇、禁飞区、自然风场扰动，在 AirSim 插件中完成场景坐标映射，完成可被 PX4 飞
控调用的高保真静态仿真环境，同步配置随机生成异构无人机 / 有人机作为动态障碍
源。
2.基于 CBMBA A * 改进的三维全局路径规划模块开发
以约束多层双向自适应 CBMBA A * 为基础，结合 OctoMap 三维八叉树栅格地图适
配 UE4 空间坐标系，优化多层扇形搜索域、自适应变步长策略，针对城市楼宇高度分
层优化代价函数，完成无人机从起点至目标点无静态建筑碰撞的全局最优预规划路径，
算法使用 Python 开发，通过 AirSim API 与 PX4 通信。
3.基于 HPER-D3QN 的动态障碍自适应避障算法开发（参考论文 2）
复用分层优先级经验回放 + DTPA 动态威胁优先级评估核心架构，搭建扇区局部观
测模型，对空域内随机出现的动态飞行器（异构有人 / 无人机）开展 T_CPA、D_CPA、
机型多维度威胁打分，训练强化学习智能体；同时优化人工势场法，引入障碍相对速度
与距离衰减系数，弥补强化学习小幅姿态微调短板，实现突发动态障碍实时紧急避让，
解决传统势场局部极小值缺陷。
4.全局规划 + 强化学习动态避障复合控制框架集成
搭建双层调度控制逻辑：常态无人机沿 CBMBA A * 全局航线飞行；机载感知检测
到动态障碍进入预警扇区时，自动切换 HPER-D3QN 决策模块输出机动指令，障碍脱离

（三）创新点与项目特色
1.双算法分层融合创新，动静障碍分治

2.UE4+AirSim+PX4+QGC 全栈一体化闭环仿真
摒弃分立仿真方案，整套验证链路统一基于 UE4 渲染引擎 + AirSim 仿真中间件
+ PX4 开源机载飞控 + QGC 地面站，从真实地图建模→算法部署→飞控指令下发→地
面实时监控一体化，仿真链路贴近真实硬件机载部署逻辑，仿真数据工程参考价值远高

场试飞。
4.静态 + 动态多工况全覆盖验证
依托 HPER-D3QN 原生异构机型处理能力，仿真覆盖无风纯静态、变风 + 少量动态、
强风 + 高密度混飞三类极限工况，完善多维度量化评价指标，验证体系完整度优于同
类单一场景研究。
5.全开源工具链，低成本易复现推广

（一）研究方案
本项目理论依托三大核心算法体系，融合两篇参考文献关键技术：
（1）全局路径规划理论：基于经典 A启发搜索，参考文献[1]CBMBA A约束多层双向自
适应算法核心思想，引入分层扇区搜索、动态变步长与自适应启发权重，完成三维空间全
局最优路径框架搭建，用于静态建筑群全局航线规划；
（2）动态避障理论：两层局部避障架构，一是改进人工势场，在 Khatib 势场中增加
障碍物相对速度项、距离衰减因子，解决传统势场局部极小；二参考文献[2]HPER-D3QN 深
度强化学习算法，引入 DTPA 动态威胁评估与分层优先级经验回放机制，针对空域异构动
目标（有人机 / 无人机）实现智能自适应避让；
（3）三维环境表征理论：采用 OctoMap 八叉树栅格结构，结合 AirSim 环境坐标映
射，完成三维空域占用地图实时构建、空间快速索引，为全局 + 局部算法提供环境数据支
撑。
研究方法与步骤：
整体技术路线：实景场景建模→全局 CBMBA A * 开发→双层局部避障设计（改进人工
势场 + HPER-D3QN）→算法融合集成→AirSim+PX4+QGC 联合仿真→UE4 可视化验证。
步骤 1：通过 OpenStreetMap API 抓取城市实景建筑数据，Blender 轻量化建模、纹
理优化，模型批量导入 UE4 引擎，在 UE 环境部署 AirSim 插件，联动 PX4 飞控完成三
维仿真空域搭建，配置静态楼宇与随机生成的动态异构飞行器障碍；
步骤 2：基于 Python 开发 OctoMap 八叉树解析模块，结合空域高程信息对 CBMBA A
进行三维适配，完成多层双向自适应全局路径规划代码开发，通过 AirSim API 完成算法
与仿真环境数据交互；
步骤 3：依托 AirSim 机载激光雷达、视觉传感器仿真模块采集实时障碍信息，分两
种局部避障：近距离突发障碍使用改进人工势场快速微调姿态，中远距离动态目标启用
HPER-D3QN 强化学习避障，搭载 DTPA 威胁分级算法评估障碍物危险等级；
步骤 4：设计有限状态机实现全局 CBMBA A与双层局部避障的调度融合：正常巡航跟
随全局航线，障碍进入预警区自动切换局部避障模块，危险解除自动回原航线；所有控制
指令经 AirSim 下发 PX4 原生飞控，QGroundControl（QGC）实时监控无人机位姿、航线
与避障状态；
步骤 5：划分纯静态障碍、低密动态障碍、高密混飞 + 变风场三组工况，以路径总代
价、算法单步耗时、静态撞障率、动态避障成功率、航线平滑度五大指标完成量化测试，
利用 QGC 导出飞行日志统计数据；
步骤 6：依托 UE4 实时渲染功能，在 AirSim 仿真环境录制不同工况下自主飞行全过
程，剪辑制作高清仿真演示视频。
技术路线：
1.OSM 城市数据采集→Blender 建筑建模优化→UE4 场景搭建→AirSim 环境配置 +
PX4 联动
2.OctoMap 三维八叉树地图构建→CBMBA A * 三维全局路径规划算法开发
3.AirSim 机载传感仿真→改进人工势场近距离避障 + HPER-D3QN 远距离动态避障
（DTPA 威胁评估）
4.状态机融合全局 / 局部算法→PX4 指令交互→QGC 地面站实时监测
5.多工况仿真测试 + 指标量化→UE4 高清渲染→项目演示视频输出
